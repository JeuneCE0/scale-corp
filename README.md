# Adopte un Artiste v2 IA

Plateforme de portfolio et vitrine d'artistes, propulsée par l'intelligence artificielle.

## Architecture

```
adopteunartistev2ia/
├── backend/          # API Node.js + Express
├── frontend/         # Application Web Next.js
├── mobile/           # Application Mobile React Native
└── docs/             # Documentation
```

## Stack Technique

- **Frontend** : Next.js (React), Tailwind CSS
- **Backend** : Node.js, Express, MongoDB
- **Mobile** : React Native (Expo)
- **IA** : Recommandations et mise en valeur des artistes

## Démarrage rapide

### Backend
```bash
cd backend
npm install
npm run dev
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```

### Mobile
```bash
cd mobile
npm install
npx expo start
```
